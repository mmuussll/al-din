# تطبيق إدارة الديون - الديون المستحقة لك

تطبيق ويب احترافي **متكامل** لإدارة وتتبع الديون التي لك على الآخرين، يعمل بالكامل في المتصفح بدون الحاجة إلى سيرفر أو تسجيل دخول.

## ✨ المميزات الكاملة

### 📊 إدارة أساسية
- تخزين محلي آمن (LocalStorage)
- إدارة كاملة للمديونين (إضافة، تعديل، حذف، أرشفة)
- تصنيف المديونين (عائلة، صديق، عميل، مورد، موظف...)
- بحث متقدم وفلترة شاملة
- ترتيب متعدد المعايير (الأحدث، الاسم، المبلغ، درجة الثقة...)

### 💰 الديون والسدادات
- تسجيل ديون متعددة لكل مديون
- تسجيل السدادات (جزئية أو كلية) مع طرق دفع متعددة
- تواريخ استحقاق وتتبع التأخير
- **نظام الأقساط** - خطط أقساط أسبوعية/شهرية/ربع سنوية
- **إدارة الشيكات** - تتبع الشيكات المعلقة، المحصلة، والمرتدة
- **وعود السداد** - تسجيل وتقييم التزامات المديونين

### 📈 التحليلات والإحصائيات
- 6 رسوم بيانية تفاعلية (تحصيل، نشاط شهري، توزيع، تطور تراكمي)
- مؤشرات أداء (KPIs) شاملة
- أعلى المديونين حسب المبلغ
- **درجة الثقة** - تقييم تلقائي لكل مديون بناءً على سلوك السداد
- **حساب الفوائد التلقائي** على الديون المتأخرة (مع فترة سماح)

### 🎯 الأهداف والتخطيط
- **أهداف شهرية وسنوية** للتحصيل
- **تنبؤ التدفق النقدي** للأشهر الستة القادمة
- **مقارنة الفترات** - الشهر الحالي vs السابق
- **التقويم البصري** - عرض كل الاستحقاقات والوعود والشيكات في تقويم

### 📁 المرفقات والمستندات
- إرفاق صور ومستندات لكل مديون (حتى 2 ميجا)
- معاينة وتحميل المرفقات
- **سجل النشاط الكامل** - تتبع كل التغييرات

### 📤 التصدير والمشاركة
- تصدير JSON / Excel / CSV
- **تصدير PDF** حقيقي للتقارير (شهري، متأخرات، شامل)
- طباعة كشوف حساب احترافية
- **تذكيرات واتساب** بنصوص جاهزة وقابلة للتخصيص

### 🔒 الأمان والخصوصية
- وضع داكن / فاتح / تلقائي
- ألوان قابلة للتخصيص (10 ألوان)
- حجم خط قابل للتعديل
- حماية بكلمة مرور
- تشفير البيانات

### 🚀 إجراءات جماعية
- تحديد متعدد للمديونين
- تذكير جماعي عبر واتساب
- أرشفة جماعية
- تصدير مجمع

### ⚡ اختصارات لوحة المفاتيح
- `Ctrl+N` - إضافة مديون جديد
- `Ctrl+F` - بحث
- `Ctrl+D` - تبديل الوضع الداكن
- `Ctrl+E` - تصدير
- `Ctrl+1-5` - التبديل بين الأقسام
- `Esc` - إغلاق النوافذ

## 🚀 التشغيل

### الطريقة الأولى: خادم محلي (موصى بها)
- **ويندوز**: انقر نقراً مزدوجاً على `start-server.bat` (يستخدم Node.js)
- أو افتح Terminal في مجلد المشروع وشغّل: `npx http-server -p 8080 -c-1`
- ثم افتح المتصفح على: `http://127.0.0.1:8080`

### الطريقة الثانية: فتح مباشر
- افتح ملف `index.html` في أي متصفح حديث
- ⚠️ ملاحظة: بعض المتصفحات تحظر تحميل `manifest.json` عند الفتح المباشر، استخدم الخادم المحلي لتجنب ذلك

### الطريقة الثالثة: VS Code Live Server
- افتح المجلد في VS Code
- ثبّت إضافة "Live Server"
- انقر "Go Live" في شريط الحالة

## 💾 البيانات

جميع البيانات تُخزن محلياً في متصفحك فقط:
- بيانات المديونين في `localStorage`
- سجل النشاط في `localStorage`  
- الإعدادات في `localStorage`
- الأهداف والقوالب في `localStorage`

يُنصح بالتصدير الاحتياطي بشكل دوري.
